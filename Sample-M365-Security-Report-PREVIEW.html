Overview - fix first

  1. [MFA] Users registered for MFA - 17 of 31 users
    Aim for every enabled user to be registered.
  2. [MFA] Admins registered for MFA - 1 of 6 admins NOT registered
    Every admin must have MFA registered before enforcing policies.
  3. [CA] MFA for all users / all apps - No enforced all-users MFA policy
    Require MFA (or an authentication strength) for All users on All cloud apps.
  4. [Entra] User consent to apps - Legacy policy - users can consent to ANY app/permission
    Use "Let Microsoft manage" or verified-publisher / low-risk permissions only.
  5. [Entra] Who can invite guests - everyone
    Limit to admins and the Guest Inviter role.
  6. [Entra] Global Administrator count - 6 (recommended 2-4)
    Keep 2 break-glass accounts plus a few named admins; use least-privilege roles for everyone else.
  7. [SharePoint] Apps that do not use modern authentication - ALLOWED (legacy authentication protocols enabled)
    SharePoint admin center > Policies > Access control > Apps that do not use modern authentication > Block access.
  8. [Exchange] Rules that bypass spam filtering (SCL -1) - 1 rule(s)
    Remove or scope tightly. These skip spam and phish filtering; a rule keyed only on a sender domain can be spoofed.
  9. [Defender] EOP: Standard Preset - Not configured
    Turn on Standard (all users) and Strict (executives/admins) in the Defender portal.
  10. [Defender] MDO: Standard Preset - Not configured
    Apply Defender for Office 365 protection to all recipients.
  11. [Defender] Spam / phish actions - Spam: MoveToJmf | High-conf spam: MoveToJmf | Phish: MoveToJmf | High-conf phish: MoveToJmf
    High-confidence phish must be quarantined; other verdicts should go to Junk or Quarantine.
